# Footer

The footer is pure ink — `--bg-inverse`, white type, mono microcopy. It's the most recognizable
Miltinson surface after the wordmark, and it's deliberately quiet.

Prototyped in `design-system-docs/ui_kits/marketing/HeaderFooter.jsx`.

## Recipe

```tsx

  return (
```

## Rules

- Hairlines on dark use `--border-inverse` (12% white) — never `--border`, which
  disappears on ink.
- Link hover shifts to `--accent-ink-inverse` — the brand color tuned for the inverted
  band, which follows the theme when the band flips. A fixed ramp step does not: the docs
  eyebrow was `--signal-400` and measured 2.07:1 the moment the band turned white.
- Mono microcopy for the tagline and legal line; body sans for nothing-else-down-here.
- The dot-grid texture is allowed here at 8% opacity, but the plain ink block is the
  default.
