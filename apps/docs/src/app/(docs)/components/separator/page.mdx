## When to use it

Use `Separator` for a hairline divider that marks a real break between content
groups — sections, toolbar clusters, nav items. If you just need whitespace, a CSS gap
is simpler and skips the ARIA semantics this component adds.

## Vertical

A vertical separator has no height of its own — give its flex container a defined
height.

## Accessibility

- Defaults to `role="separator"` with `aria-orientation` matching `orientation` — a
  static divider, not a focusable, resizable splitter.
- `role` is overridable: if the separator is purely decorative spacing with no
  thematic-break meaning, pass `role="none"` yourself to drop it out of the
  accessibility tree. The default assumes it _is_ meaningful.
