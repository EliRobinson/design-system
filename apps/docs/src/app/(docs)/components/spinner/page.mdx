## When to use it

Use `Spinner` for a small, indeterminate "working" indicator — you don't know how long
it'll take. Use `Progress` instead the moment you actually know the percent complete.

## Accessibility

- Renders `role="status"` with `aria-label={label}` (default `"Loading"`) — a live
  region announced once when it mounts. `role` is fixed: the type omits it from the
  props you can pass, so you can't accidentally break the live region.
- When adjacent visible text already says the same thing — a "Saving changes" button,
  for example — pass `aria-hidden="true"` on the `Spinner` so the two don't both get
  announced, as in the button demo above.
- Give it a specific `label` when the default "Loading" isn't precise enough ("Loading
  invoices") and no visible text nearby already says so.
