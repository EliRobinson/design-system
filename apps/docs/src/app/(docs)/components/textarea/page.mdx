## When to use it

`Textarea` is `Input`'s multiline sibling — same label/hint/error wiring, same required
`label`. Use it for anything that needs more than one line: a message, notes, a
description. Reach for `Input` when a single line is enough.

## Accessibility

- Same wiring as `Input`: a real `<label htmlFor>`, `hint`/`error` text linked through
  `aria-describedby`, and `aria-invalid="true"` plus `role="alert"` on the error text
  when `error` is set.
- The native resize handle is left on (`resize: vertical` in the stylesheet) — the
  component doesn't disable it.
- The ref forwards to the underlying `<textarea>`.
