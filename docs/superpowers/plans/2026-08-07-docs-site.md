# Docs Site Implementation Plan

> **For agentic workers:** This plan is executed inline in a single autonomous session
> (per the run brief), with subagent fan-out only for the per-component doc content.
> Spec: `docs/superpowers/specs/2026-08-07-docs-site-design.md` + the run prompt at
> `docs/prompts/fable-docs-site.md`.

**Goal:** A Next.js App Router docs site at `apps/docs` — Overview, Foundations,
Components (44), Patterns, Guidelines, Build with AI — plus a manifest-driven AI layer
(`/llms.txt`, `/llms-full.txt`, `/r/[component].json`, prompt templates, extended
contracts.json), all green under the root verification commands.

**Architecture:** One build-time extraction (`react-docgen-typescript`) emits
`component-manifest.json`; props tables, search index, and AI artifacts all read that
manifest and nothing else. Site consumes `@elirobinson/react` + `@elirobinson/tokens` as
workspace deps and is styled exclusively with system tokens/components.

**Tech Stack:** Next.js 16.3.0 (App Router, Turbopack), @next/mdx, React 19.2,
react-docgen-typescript 2.4.0, shiki (build/server-side highlighting), vitest.

## Global constraints (from spec — verbatim where exact)

- Imports in every example and artifact use package subpaths only; bare
  `@elirobinson/react` is wrong and must not appear.
- No Tailwind, no CSS-in-JS runtime, no third-party docs framework.
- No changes to `packages/react/src/components/`; no Storybook changes; no publishing,
  version bumps, or changesets; no reorganizing `docs/agents/` or `design-system-docs/`
  (except one SKILL.md cross-link).
- Brand: "I" never "we"; sentence case headings; ink-led + Miltinson Amber accent,
  Forest secondary; Geist + JetBrains Mono; no gradients/purple/emoji; sharp 4–6px
  radii; hairline borders; 16px min text; WCAG AA; focus-visible rings;
  prefers-reduced-motion honored; wordmark "Miltinson." with amber period.
- Prettier/eslint configs at root are the style authority.
- Node >= 24, pnpm 10.11.1, TS 6.0.3 (repo-wide).

## Manifest schema (the contract everything reads)

```ts
type ComponentManifest = {
  generatedAt: string;
  components: ComponentRecord[];
};
type ComponentRecord = {
  name: string; // "Button"
  slug: string; // "button" (route + /r/ key)
  tier: 'atoms' | 'molecules' | 'organisms';
  importPath: string; // "@elirobinson/react/components/atoms/Button"
  stylesheetPath: string | null; // "@elirobinson/react/styles/atoms/Button.css"
  description: string; // from source JSDoc if present, else ''
  props: PropRecord[];
  subComponents: { name: string; props: PropRecord[]; description: string }[];
  exportedTypes: string[]; // e.g. ["ButtonVariant","ButtonSize"]
  constraints: string[]; // machine-readable constraint ids from contracts.json
  extractionGaps: string[]; // honest record when docgen couldn't extract something
};
type PropRecord = {
  name: string;
  type: string;
  required: boolean;
  defaultValue: string | null;
  description: string;
};
```

## Tasks

Tracked in the session task list (9 tasks). Order: scaffold → pipeline → chrome →
exemplar → fan-out (parallel with foundations/patterns/guidelines/AI layer) → verify.
Verification cadence: after each task, `nx run docs:build` + targeted checks; full root
suite at the end and once mid-run after the fan-out lands.

Key decisions locked here:

1. **Committed generated manifest.** `src/generated/component-manifest.json` is checked
   in so lint/typecheck work on a fresh clone; the extract script runs before build/dev
   so it can never be stale in an artifact.
2. **Docs consume built package dists** via workspace deps + Nx `dependsOn: ["^build"]`
   (same resolution a real consumer gets, exercising the real exports map). Storybook
   aliases to source; the docs site deliberately does not — it validates the package
   boundary.
3. **No rehype/remark plugins** — Turbopack requires serializable MDX options; syntax
   highlighting happens in the `pre` component mapping via shiki instead.
4. **Per-component `page.mdx` + one client demo file** rather than a single dynamic
   route — statically analyzable imports, natural code-splitting, subagent-friendly.
5. **Site search dogfoods `CommandPalette`** fed by manifest + a static page registry.
