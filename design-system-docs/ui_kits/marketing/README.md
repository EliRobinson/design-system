# Marketing UI Kit

Recreation of the miltinsons.com homepage in the Miltinson design system.

**Components**

- `HeaderFooter.jsx` — sticky header with primary nav + CTA, ink footer
- `Sections.jsx` — `<Hero />`, `<FeaturedApps />`, `<CoachingBand />`, `<ServicesBand />`
- Uses primitives from `../_shared/Primitives.jsx`: `Wordmark`, `Eyebrow`, `Tag`, `Button`, `RuleLink`

Open `index.html` to see the assembled homepage.

**Notes**

- Featured-apps thumbnails use placeholder visuals (emoji on amber gradient for Kids Recipes; mono equation on ink for Maths). Swap with real screenshots when available.
- The Coaching Guides band shows three stylized "guide cards" — replace with real cover art.
