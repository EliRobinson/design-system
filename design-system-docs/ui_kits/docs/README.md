# Docs / Guide UI Kit

Long-form reading layout used for:

- Digital guides and handbooks
- Documentation for any sub-app
- Blog / essay posts

**Layout**: sticky table of contents (left) + 720px reading column with editorial type stack, accent blockquotes, mono code blocks.

Every string this kit renders comes from `../_shared/content.js`.

Open `index.html` to read a sample chapter.
