# Social carousel template

1080×1080 slide starters for Instagram/LinkedIn carousels. Open `carousel.html` in a browser and export each slide as PNG.

## Slides

1. Title — brand + tagline
2. Point — single practical tip
3. Closer — CTA to miltinsons.com

## Brand notes

- Flat ink + amber only; no gradient meshes.
- Geist for headlines, JetBrains Mono for eyebrows.
- Export at 2× for crisp mobile feeds.
