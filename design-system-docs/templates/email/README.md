# Email template

Starter HTML email aligned with Miltinson tokens. Replace copy and links before sending.

## Usage

1. Open `newsletter.html` in a browser to preview.
2. Inline styles are already embedded for email client compatibility.
3. Swap the hero CTA link and footer links for your campaign.

## Brand notes

- Sentence-case headings, mono eyebrows, ink + amber accents only.
- Min 16px body text; 44px touch targets on mobile links.
- No gradients or decorative emoji in system copy.
