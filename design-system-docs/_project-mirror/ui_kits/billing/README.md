# Billing & checkout kit

Three views in one flow: manage → plans → checkout → back to manage.

**Rules**

- **One featured plan only**, marked by an ink border and a "Most picked" badge — never by a coloured card or a gradient.
- **Money is always mono**, right-aligned in tables, with tax shown as its own line before the total.
- **Say what happens next to the money**: renewal date, cancellation route, and "no contracts required" — the brand's promise, restated where it costs something.
- **The yearly discount is stated in the toggle** ("Yearly — 2 months free"), not in an asterisk.
- Card fields carry real `autocomplete` tokens so password managers fill them.
