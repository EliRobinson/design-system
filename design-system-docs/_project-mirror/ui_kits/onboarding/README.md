# Onboarding kit

Four steps: You → Your work → First product → Done. Fixed header and footer, one 560px column, Stepper plus Progress so people can see how much is left.

**Rules**

- **Say the length up front** — "Two questions, then you're in."
- **Every step is skippable after the first**, and the skip is a plain link, not a hidden one.
- **Nothing is destructive and nothing is final**: "you can change any of this later" appears on the first step, "nothing goes live until you publish" on the product step.
- **The done screen suggests three next moves with reasons**, each with a small secondary action — no confetti, no celebration modal.
- Primary action sits bottom-right, Back bottom-left, both pinned — the position never moves between steps.
