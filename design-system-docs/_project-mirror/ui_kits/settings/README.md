# Settings kit

Four tabs on a 880px column: Profile, Security, Team, Notifications.

**Rules**

- **Label-left, control-right rows** at 240px / 1fr, separated by hairlines — no cards inside cards.
- **Destructive actions live in a bordered danger zone at the bottom**, never inline with saves, and always behind a Dialog that names what is lost and the grace period.
- **Toggles apply immediately; text fields need a Save.** Say which is which by putting Save/Discard under a rule at the end of the form.
- Session rows name the device, the place and the time — the three things a person checks when something feels wrong.
