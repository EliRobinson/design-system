Regenerates the three files a design-project push builds from, and pushes the result to
the `Miltinson Design System` project on claude.ai/design.

`packages/react/index.d.ts` gains `dist/lib/marks` and moves `DecisionCard` into its
sorted position — the file is generated by `.design-sync/gen-entry.mjs` and had drifted
since `marks` was added. It lives in the package root, which `files: ["dist","src"]`
excludes, so nothing about the published tarball changes and this changeset is empty on
purpose.

`design-system-docs/styles.css` picks up the same `DecisionCard` reordering, and
`design-system-docs/guidelines/colors-palettes.html` re-renders with section labels that
name the attributes each panel sets (`data-palette="slate" data-theme="dark"`) instead of
the old `slate · dark` shorthand.
